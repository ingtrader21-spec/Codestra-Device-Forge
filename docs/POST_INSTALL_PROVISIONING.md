# Post-install provisioning

After a successful OS install and hardware certification, Device Forge offers an optional app-provisioning step.

Rules:
- explicit approval is required;
- only apps compatible with the installed OS/device are offered;
- official project/vendor sources or approved app stores are preferred;
- package signatures/hashes are verified when available;
- failures never roll back or misreport OS installation;
- social/messaging apps are selectable individually or through a user-defined profile;
- do not bundle credentials or automatically sign users in.

The OS catalog is compatibility-first. An OS being listed does not mean it can be flashed to every phone.
